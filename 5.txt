Страница оплаты
	Заголовок: "ОПЛАТА"
	В верхней части отображаются товары из корзины:
    		для каждого товара:
        	название, изображение, цена, количество
	Поле для ввода адреса пользователя:
    		"Введите ваш адрес"

Функция подтверждение оплаты
	Проверка наличия товаров на складе:
    		для каждого товара в корзине:
        		проверить, есть ли на складе достаточно единиц
        		если нет, вывести сообщение: "Недостаточно товара на складе"
        		и остановить процесс
	Проверка адреса:
    		проверить, существует ли указанный адрес
    		определить расстояние до адреса
    		показать примерное ожидание доставки
	После нажатия "ОПЛАТИТЬ":
    		проверить баланс пользователя:
        		если баланс >= итоговая сумма корзины:
            		списать сумму со счета пользователя
            		для каждого товара:
                		уменьшить количество на складе на купленное количество
                		создать запись в "текущих заказах" с уникальным ID
            		очистить корзину
            		перейти к странице подтверждения/успешной оплаты
        	иначе:
            		вывести сообщение: "Недостаточно средств! Пополните кошелек."

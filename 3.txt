Название: "COOLFIIT_SHOP"

Меню вверху слева:
    кнопка Каталог (при клике вызывает ОкноКаталога)
    кнопка Корзина (при клике вызывает ОкноКорзины)
    кнопка Профиль (при клике вызывает ОкноПрофиля)
    кнопка Текущие заказы (при клике вызывает ОкноТекущихЗаказов)
    кнопка Прошлые заказы (при клике вызывает ОкноПрошлыхЗаказов)

Внизу:
    - "Здесь могла быть ваша реклама. Звоните 88005553535"

ОкноКаталога
	для каждого товара из базы данных:
    	показать строку:
        	изображение товара
        	название товара
        	цена
        	кнопка "Добавить в корзину"

ОкноПрофиля
	отобразить:
    	ID
    	Имя
    	Фамилия
	Электронная почта
	Баланс

ОкноКорзины
	отобразить список добавленных товаров:
	    для каждого товара:
	        изображение, название, цена
	        кнопка "Убрать из корзины"
	    кнопка "КУПИТЬ"

ОкноТекущихЗаказов
	для каждого текущего заказа:
	    показать:
	        номер заказа (ID)
	        краткое описание содержимого
	        кнопка "Подробнее"

ОкноПрошлыхЗаказов
отобразить список завершённых заказов:
	ID заказа
	содержание

при нажатии "Подробнее":
    показать все содержимое заказа:
        список товаров, цена, примерное ожидание
